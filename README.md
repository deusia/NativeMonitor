# NativeMonitor

面向 Apple Silicon 的 macOS 菜单栏性能监控原型，使用 SwiftUI、AppKit 和系统计数器。CPU、GPU、内存、磁盘和网络均显示本机采样数据；GPU 驱动计数器属于实验性数据源。

## 指标与口径

| 类型 | 主指标 | 其他参考指标 |
| --- | --- | --- |
| CPU | 全部逻辑核心的使用率之和（可切换为整机比例） | 各逻辑核心使用率、用户／系统／空闲；逻辑核心数、系统运行时间、1/5/15 分钟系统负载 |
| GPU | 驱动报告的设备利用率 | 渲染器、分块器利用率，驱动内存与核心数、设备名称、Metal 建议工作集及 AI 加速能力 |
| 内存 | 活跃、不可换出和压缩内存之和 | 物理内存、压缩、交换已用、活跃、非活跃、不可换出、空闲页和已用比例 |
| 磁盘 | 块存储设备读取速率 | 写入速率、设备累计读写、用户主目录所在卷总容量和可用容量 |
| 网络 | 运行中 `en` 接口的接收速率之和 | 发送速率、接口数量和名称、接口累计收发 |

每项展示本次运行期间、最多 30 分钟的样本平均值和峰值；图表可选择最多 5 或 30 分钟，只绘制启动后的真实样本；详情页提供分项曲线，缺失样本不会连接。均值为采样点的算术平均，不是时间加权平均。CPU、磁盘和网络速率需要两次采样，首次显示等待；计数器回退或网络接口变化时重新建立基线。采集失败时显示不可用，并清除对应曲线，后续继续重试。内存单位采用十进制 GB，速率按十进制自动选择 B/s、KB/s、MB/s 等单位；非零数值低于显示精度时显示为小于阈值。

CPU 详情根据系统的逻辑核心簇 ID 分组，默认折叠；簇总量为各核心使用率之和，平均值以簇内核心数归一化。无法读取完整簇拓扑时直接显示逻辑核心。CPU 核心类别通过系统拓扑及性能等级数量匹配推断；数量不唯一或信息不完整时使用中性色且不标注类别。M5 Max 的配色参考 Apple 官方芯片宣传图，紫色区分核心类别，并非 Apple 对各类核心指定的颜色。CPU 使用率来自各核心系统 CPU 时间差，用户时间包含 nice；核心总量口径下每个逻辑核心满载为 100%，例如 18 核的上限为 1800%；整机比例是各核心的平均值，上限为 100%。系统负载并非 CPU 百分比。内存分项曲线展示活跃、非活跃、不可换出、压缩和空闲页；每张图的纵轴根据自身数据独立缩放，图形高度不能直接比较，各曲线也不能全部相加作为主指标。内存主指标不包括非活跃页，但活跃页可能包含文件缓存；该值不是应用内存或内存压力，与 `top`、活动监视器的已用内存口径不同。GPU 字段来自 IORegistry 的 `IOAccelerator` / `PerformanceStatistics`，只接受单个 AGX 驱动；字段与统计窗口没有稳定的公开契约，不是进程 GPU 时间，渲染器和分块器利用率不能相加；驱动的系统内存统计不等于独立显存，Metal 建议工作集不等于实际占用。Metal Apple10 及以上 GPU 的每核心 Neural Accelerator 与独立 Apple Neural Engine 是不同硬件；本应用目前无法获取两者的独立实时利用率，不以 GPU 总利用率代替。GPU 核心数来自实验性驱动字段。磁盘速率为系统识别的块存储设备之和，可能包含外接设备；容量属于主目录卷，受 APFS 共享空间影响。网络统计使用 64 位接口计数器，包含局域网流量，只选择名称以 `en` 开头且处于运行状态的接口，不包含 VPN 等其他接口；多个接口的统计也可能受系统拓扑影响，不等于互联网流量。

系统指标及 GPU 分别在后台采样，采样间隔可设为 1、2 或 5 秒；某一采样长时间阻塞时显示超时，并不重复堆积请求。历史仅保存在内存中，退出后消失。无网络上传或特权 helper。

## 操作

- 点击菜单栏读数或 ⌘O：开关概览；Esc 关闭。
- ⌘1：打开详情；⌥⌘1～5：切换 CPU、GPU、内存、磁盘、网络。
- ⌃⌘S：收起或展开侧栏；⌘Q：退出。
- 设置可调整采样间隔、CPU 口径、主读数小数位、外观和透明度；历史范围也会保存。设置自动保存在本机，不修改系统设置。

## 构建和验证

需要 Apple Silicon Mac、Swift 6 工具链，以及包含 macOS 26 Glass API 的 Xcode SDK。最低部署版本为 macOS 14，26 及以上使用 Glass API；当前仅在开发机器的系统和 SDK 上验证。

```sh
swift test
./build.sh
```

构建脚本在仓库上级目录生成 `NativeMonitor.app`，使用本地 ad-hoc 签名；尚未进行 Developer ID 签名或公证。背景模糊目前依赖私有系统接口，系统升级可能使效果失效；透明度回退使用普通背景。跨硬件、旧系统、长期资源占用、受控负载精度和完整无障碍验收仍需验证。仓库中其他材质验证文档是历史迭代记录，不代表当前数据采集方案。
