# 性能监控原型 0.2

Apple Silicon 个人自用的 SwiftUI + AppKit 原型。GPU 为实验性实时数据，CPU、内存、磁盘、网络仍为模拟数据。无网络上传、特权 helper、管理员权限或私有函数调用。

## 启动与操作

打开同级 `NativeMonitor.app`。菜单栏显示 CPU 百分比、内存和下载三个模拟读数，具体口径见提示文字。总宽度按所有演示场景的最大文字宽度计算，当前 120 pt，初版为 266 pt。

- 点击菜单栏读数或 ⌘O：开关概览；Esc 关闭。
- ⌘1：打开详情；详情关闭后菜单栏仍驻留。
- ⌥⌘1～5：依次选择 CPU、GPU、内存、磁盘、网络。
- ⌃⌘S：收起/展开侧栏；恢复按钮常驻。
- ⌘Q：退出。
- 演示设置只改变原型场景、外观和透明度，不修改系统设置。

## 界面

概览采用原生 NSPanel，概览总容器与详情总承托背景统一使用 behindWindow 模糊；卡片间隙、侧栏间隙和内容背后都属于同一块背景。卡片与小模块只保留原生 clear glass 边缘和交互，不重复叠加 HUD 模糊。

底板使用 NSVisualEffectView 的 hudWindow 材质，取消外层玻璃描边和强调状态；通过公开 maskImage 在四边渐退，保留后方色彩并模糊细节；不对前景文字或图表做整体模糊。减少透明度时回退实色。顶部不重复显示程序名。

选中项具有色彩、勾选标记和无障碍选中语义。侧栏点击附加约 0.42 秒柔和扩散光晕。窗口打开约 0.18 秒、关闭约 0.13 秒，淡入淡出并轻微缩放；每个窗口的过渡有独立标记，旧完成回调不能关闭已重新打开的窗口。GPU 数字与真实采样曲线使用约 0.25 秒过渡；模拟数据不会伪装成实时刷新。系统减少动态效果时取消自定义动画。

应用或系统减少透明度时回退实色与普通按钮。文本使用随外观变化的高对比前景；不会保证任意极端桌面背景上的对比度与控制中心完全相同。使用公开材质 API，不声称复制系统控制中心的私有实现。

## GPU 来源与边界

通过公开 IOKit 读取本机 `IOAccelerator` 节点的 `PerformanceStatistics` 字典，仅接受单个 AGX 驱动来源：

- `Device Utilization %`：驱动报告的设备利用率。
- `Renderer Utilization %`、`Tiler Utilization %`：分别显示，不相加。

本机实际驱动为 `AGXAcceleratorG17X`，无需提权即可读取。驱动字段没有稳定公开契约；统计窗口也未通过受控负载校准，不能承诺跨系统、跨硬件稳定。不是进程 GPU 时间，不伪造显存或 GPU 进程列表。

每 2 秒由后台工作线程读取，同一时刻最多一个请求；主线程计时器在 common run-loop 模式工作。拒绝缺失、布尔、非数值、非有限值或超出 0～100 的主计数器。失败时显示不可用并清空当前曲线，下一轮重试；超过 6 秒未更新也显示不可用。若底层 IOKit 调用阻塞，不再堆积新请求，界面仍可操作，提示重新打开程序。

只保留本次启动后的最多 30 分钟内存样本；退出不持久化。短历史按已有真实时长展开，界面说明所选 5/30 分钟为上限，不补造之前的样本。模拟“全部暂无样本”仍会隐藏 GPU 读数，便于空态演示。
