# 实机数据核验记录

2026-11-13，在本机 Apple Silicon、macOS 27.3 上对照系统工具；采样时间并非完全同步，差异不能作为所有设备的精度保证。计数与速率均按各自说明的范围比较。

- CPU：使用一个单核持续计算进程，在相近的两秒窗口内，监控值 11.19%，`top` 的用户 5.79% + 系统 5.39% = 11.18%。其他窗口因采样边界和后台负载波动而不同。
- 内存：`vm_stat` 页大小为 16,384 字节；监控的活跃、不可换出、压缩页与 `vm_stat` 的对应页数相符。分配并触碰 512 MiB 时主指标从 20.43 GB 升至 20.87 GB，释放后回到 20.42 GB；其间其他进程也在变化。`top` 的 PhysMem 使用量包含不同范围的页，不能直接作为该主指标的相等对照。
- 磁盘：临时写入 64 MiB 随机数据并同步至文件，监控在相邻一秒采样窗口记录约 52.48 + 16.73 MB 写入；`iostat` 在相近窗口记录 65.93 MiB/s（约 69.13 MB/s）的设备总吞吐。采样边界不同，且可能有其他设备 I/O。主目录卷容量与 `df` 相符。另对 64 MiB 临时文件使用 `F_NOCACHE` 写入和读取，读取约 67.11 MB，监控相邻窗口累计约 66.81 MB；窗口未完全对齐。
- 网络：修复前，普通进程读取 `NET_RT_IFLIST2` 的接口计数仅得到低 32 位且低位被量化；例如接收约 2.63 GB，而同一接口 `netstat` 约 393.47 GB。改用 `IFDATA_GENERAL` 后，前后夹取的采样与 `netstat` 的 64 位收发计数一致，已加入回归测试。下载约 21.59 MB 文件时，`netstat` 接收增加约 23.62 MB；监控相邻窗口合计约 23.45 MB，差异来自采样时间、协议开销和其他流量。另发送 1 MiB 随机测试数据，`netstat` 发送增加约 1.20 MB，监控在相邻窗口合计约 1.19 MB；服务端返回 HTTP 413，因此这只验证了链路发送计数，未验证服务端接收成功。

本次未验证网络断开重连、外接磁盘热插拔、长时间运行，以及其他系统版本或硬件。GPU 驱动口径未做受控负载校准。
