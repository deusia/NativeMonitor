# 兼容性记录

最低部署版本与实际验收范围分别记录。能够构建、测试通过或进程启动，并不能单独证明所有界面与指标可用。

| 环境 | 已执行的验证 | 尚未覆盖 |
| --- | --- | --- |
| Apple M5 Max，macOS 27.3 (26C5047e)，Xcode 27.2，macOS SDK 27.2 | 2026-11-17：0.0.94 的 53 项测试、Release 构建、arm64 架构及签名完整性检查通过；启动进程冒烟检查通过；概览和 CPU 详情已打开并截图 | 所有页面与交互、长期稳定性、受控负载精度、完整无障碍验收 |
| macOS 14 起的其他系统及其他 Apple Silicon 芯片 | 仅声明最低部署版本为 macOS 14 | 未完成实机兼容性验收 |
| Intel Mac | 不支持，构建脚本会拒绝非 arm64 环境 | 无 Intel 支持计划承诺 |

GPU 驱动计数器、ANE 功耗和 AppleSMC 传感器依赖硬件及系统实现；背景模糊依赖私有接口，系统升级可能导致失效。某项不可用不代表其他指标均不可用。

GitHub Actions 的具体系统、Xcode 和 SDK 以对应运行日志为准；托管虚拟机结果不作为真实 GPU、ANE 或传感器兼容性的证明。

欢迎提交其他环境的结果，请附应用版本或提交号、芯片、macOS 版本、实际检查项目及失败情况；不要附设备序列号或其他私人标识。
